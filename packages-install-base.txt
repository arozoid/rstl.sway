# rstl.sway package list - base edition (installer: bin/install-base.sh)
#
# Sections, read by bin/install-base.sh:
#   #@core             one atomic pacman transaction. A name that does not
#                      resolve is reported and left out instead of voiding the
#                      whole transaction (pacman resolves every target before it
#                      installs anything).
#   #@optional         installed one at a time, so a name that does not resolve
#                      skips only itself. Used for the rstl-repo extras.
#   #@program:vim      selected by RSTL_PROGRAM=vim or --program vim
#   #@program:mouse    selected by RSTL_PROGRAM=mouse or --program mouse
#                      (micro + rovr)
#   #@firefox          selected by RSTL_FIREFOX=1 or --firefox
#
# Renamed packages are NOT listed here: they are resolved by
# install_or_fallback in bin/install-base.sh (fd-find/fd, the cursor themes, ...),
# because the name that resolves depends on the distribution.
#
# The base edition is the bare sway desktop: no swayidle/swaylock, no
# NetworkManager (wpa_cli via wpa_supplicant), no Bluetooth, no codecs, no
# TUIs, no editor and no program configuration.
